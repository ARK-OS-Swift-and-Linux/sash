# Security Policy

Security is paramount for `sash`. As the primary terminal environment, it processes untrusted input, environment variables, and executes processes.

## Supported Versions
Only the `main` branch is actively supported with security patches.

## Reporting a Vulnerability

If you discover a potential security vulnerability in `sash` (such as command injection escapes, arbitrary code execution flaws, or privilege escalation paths), please **do not** open a public issue.

Send an email to our security team at `arkosgogs@gmail.com` with:
- A detailed description of the vulnerability.
- Steps to reproduce it.
- Its potential impact on the system.

We will coordinate a patch and a secure release schedule.
